# First Anniversary Page

Open `index.html` directly in a browser. The site is ready for GitHub Pages deployment through `.github/workflows/pages.yml`.

The supplied couple photo is `hero-photo.jpg`, and the authorized `to-love.mp3` file is included for the in-page music button.

## Publish

1. Create an empty GitHub repository.
2. Add it as the `origin` remote.
3. Push the `main` branch.
4. In GitHub, open **Settings → Pages** and choose **GitHub Actions** as the source.

The workflow will publish the site at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
